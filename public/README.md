# 🍎 Food Pun Fortune Teller & Bilingual Learning Module

An interactive, gamified educational web application built with **React** and **Tailwind CSS**. Designed for young and ESL learners, this module bridges language acquisition and modern front-end engineering through tactile 3D flashcards, animated error-handling feedback, and native browser speech synthesis.

## ✨ Key Features

- **3D Perspective Flashcards:** Custom CSS 3D transforms (`perspective-1000`, `transform-style-3d`, `backface-hidden`) for smooth, tactile card flipping.
- **Interactive Matching Game:** Randomized game loops connecting food items to idiomatic puns with dynamic success states and animated shake effects (`animate-shake`) on incorrect matches.
- **Web Speech Integration:** Leverages the native browser `SpeechSynthesisUtterance` API for zero-latency audio pronunication feedback.
- **Bilingual Localization:** Seamlessly pairs English idioms and phonetics with Traditional Chinese translations and Zhuyin guides.
- **Expandable Wordplay Guide:** Slide-out drawer architecture providing deep linguistic breakdowns for educators and students.

---

## 🛠️ Tech Stack

- **Framework:** React (Functional components, Hooks: `useState`, `useEffect`)
- **Styling:** Tailwind CSS (Utility-first design systems, custom animations)
- **Icons:** Lucide React
- **APIs:** Web Speech Synthesis API
